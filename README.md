# VOID RIDER TRILOGY // Unified Starship Audio Console

Un unico motore Web Audio DSP + MediaPipe Face-Mapping (478 punti) con **3 interfacce switchabili in tempo reale** e **3 entry-point dedicati** (Desktop + 2 App Smartphone semplificate):

1. **`index.html` — Desktop Bridge**: Plancia completa con Face-Mapping 478pt, Simulatore Mouse, Multi-Source Audio (Synth procedurale, Upload MP3/WAV, Tab Audio Spotify/YouTube, YouTube Deck, Microfono) e **3 pulsanti live** per cambiare interfaccia in tempo reale (`01 VOID RIDER`, `02 ENTERPRISE 2013`, `03 SECTION 31 CYBER-TREK`).
2. **`mobile.html` — Mobile Bridge (Cam + Touch XY)**: Ottimizzata per smartphone in verticale con fotocamera frontale oppure Touch XY Pad + pulsanti hold per Echo/Shimmer.
3. **`mobile-pocket.html` — Pocket Lite (Zero-Lag)**: Versione ultra-leggera senza WASM/webcam per girare fluida su qualsiasi telefono.

## Pubblicazione su GitHub Pages
```bash
git remote add origin https://github.com/TVint/void-rider-trilogy.git
git branch -M main
git push -u origin main
```
Poi attiva **Settings → Pages → Deploy from `main` branch**.
